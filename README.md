# Garage Barbershop, garagebarbershop.com.ua

Односторінковий сайт барбершопу в Ірпені. React 19, Vite, Tailwind 4, motion,
компоненти motion-primitives. Збірка статична: на хостинг іде лише вміст `dist/`.

## Команди

```bash
npm install        # один раз
npm run dev        # http://127.0.0.1:8767
npm run build      # збірка в dist/ з пререндером HTML
npm run preview    # подивитись зібране
```

`build` робить три речі: перевіряє типи, збирає клієнт і вкладає готову
розмітку в `dist/index.html`, щоб пошуковик і превʼю в месенджерах бачили
текст, а не порожній `<div id="root">`.

## Викласти на хостинг

Сайт їде на Cloudflare Workers зі статичними файлами:

```bash
npm run deploy        # збірка і викладка
npm run cf:dev        # той самий воркер локально, з емуляцією KV
```

Сторінка лишається статичною: HTML, скрипти, стилі й фото своїх майстрів
Cloudflare віддає напряму, і код воркера на них навіть не запускається.
Воркер (`worker/index.js`) втручається лише в шляхи, перелічені в
`run_worker_first`:

| Шлях | Що робить |
|---|---|
| `GET /data/content.json` | живий вміст із KV, з відкотом на файл зі збірки |
| `GET /data/availability.json` | вільні вікна з Altegio, див. «Вільні вікна» |
| `GET /uploads/<slug>.jpg` | фото майстрів, доданих із телеграма |
| `POST /api/telegram` | вебхук телеграм-бота, стан у Durable Object `BotState`, див. `../bot/README.md` |
| `POST /api/content`, `PUT /api/photo/<slug>` | сюди писав бот із ноутбука; лишено для відкату |

Перший раз потрібні простір KV і секрет:

```bash
npx wrangler login
npx wrangler kv namespace create CONTENT   # id вписати у wrangler.jsonc
npx wrangler secret put WRITE_SECRET       # те саме значення йде в bot/.env
```

Для бота в хмарі ще `BOT_TOKEN`, `BOT_ALLOWED` і `TG_SECRET`, див.
`../bot/README.md`.

Секрет мусить бути **ASCII**: він їде в заголовку `Authorization`, а той не
приймає кирилицю. Найпростіше згенерувати: `openssl rand -hex 24`.

Кеш заданий у `public/_headers`. Для `/data/*` там навмисно `no-store`:
інакше CDN віддавав би стару копію і правки з телеграма були б невидимі.

Без Cloudflare сайт теж працює: це звичайна статика, і вміст `dist/` можна
залити на будь-який сервер без Node. Просто живого редагування там не буде.

## Структура сторінки

Герой з вільними вікнами → Прайс → Майстри → Про нас → Контакти.

- Карта в контактах: ембед Google без ключа, запит за назвою закладу, світлий монохром через CSS-фільтр.
- Секції «Простір», «Відгуки», «Батько + син» пробувались і зняті.
- Роботи «до і після» потребують фото з Instagram.
- «Про нас» показує шість останніх постів з Instagram, кожна плитка веде на
  свій пост. Поки це знімок від 24.09.2026 (`src/lib/instagram.ts`, фото в
  `public/img/instagram/`): ключа до API Meta ще немає. Коли він буде, воркер
  віддаватиме свіжі пости в тому самому вигляді.

## Аналітика

PostHog, а не Google Analytics: власнику потрібні записи сесій і теплові
карти, чого GA4 не вміє.

Увімкнути: завести проєкт на posthog.com (європейська хмара) і вписати
публічний ключ проєкту в `KEY` у `src/lib/analytics.ts`. Більше нічого:
`autocapture` запамʼятовує кожен клік по будь-якому елементу сам, розмічати
сторінку руками не треба. Названі події (`booking_open`, `slot_tap`,
`tel_click`, `tel_copy`, `social_click`, `route_click`) шле `src/lib/track.ts`.

Ключ публічний за задумом: він і так лежить у кожній збірці, яку бачить
відвідувач. Тримати його в таємниці немає сенсу й можливості.

| | |
|---|---|
| Вага | 93 КБ gzip окремим шматком, вантажиться після простою браузера. З порожнім ключем збірник викидає його цілком і це нуль байтів |
| Куки | немає, сховище тільки `localStorage`, тож банер згоди не потрібен |
| Профілі людей | не заводяться, ми нікого не ідентифікуємо |
| Поля вводу | маскуються, та їх на сайті й немає: запис іде на боці Altegio |

Блок GA4 в `index.html` лишився закоментованим на випадок, якщо колись
знадобиться ще й він. Обидва можуть працювати разом, `track.ts` шле в обидва.

## Живий вміст із телеграма

Ціни й склад майстрів можна міняти без збірки, ботом із теки `../bot`. Він пише
`public/data/content.json`, а сайт опитує цей файл: раз на 3 секунди, поки
вкладка на очах, і раз на пів хвилини у фоні (`src/lib/live.ts`).

Повні дані далі лежать у збірці й саме вони йдуть у пререндер, тож пошуковик
і перший кадр ніколи не порожні. `content.json` лише накладається зверху.
Файла немає, мережа впала, JSON побитий: сайт мовчки лишається на вбудованих
даних, зламати сторінку ботом не можна.

Майстру, доданому з телеграма, картка малює звичайний `img` замість `picture`:
у нього є тільки `jpg`, а браузер не відкочується на `jpg`, якщо `webp` у
`picture` просто відсутній. Без фото показуються ініціали на темній плитці.

Щоб прибрати цю можливість, досить видалити `src/lib/live.ts` і повернути
прямі імпорти `priceRows` і `barbers` у `PriceSection`, `MastersSection`
і `SlotsPanel`. Налаштування бота див. `../bot/README.md`.

## Вільні вікна

Вікна живі. Раз на десять хвилин воркер питає Altegio найближчі вікна
кожного майстра на кожну з трьох послуг панелі (`book_staff_seances`) і
кладе готовий JSON у KV. Сайт читає `/data/availability.json`, а воркер
віддає його з KV. Партнерський ключ Altegio лежить секретом воркера
`ALTEGIO_TOKEN`, локально в `.dev.vars`.

Хто в панелі, з якими послугами й цінами, береться з
`public/data/availability.json`. Його вікна (`dayOffset` + `time`) це макет:
їх бачить лише `npm run dev`. Якщо свіжих живих даних немає пів години,
адреса віддає 503 і панель ховається: вигадане вікно гірше за жодне.

Altegio віддає вікна лише найближчого вільного дня, не більше пʼяти.
Майстри, додані ботом, у панель поки не потрапляють: для них у шаблоні
немає id послуг.

### A/B-тест порядку майстрів

Погоджено 24.09.2026, код у `src/lib/slotsTest.ts`. Варіант A: вгорі той,
хто звільниться найраніше. Варіант B: рядки з різних рівнів, і серед них
завжди топ. Відвідувач отримує варіант випадково, браузер його памʼятає.
Варіант іде в PostHog властивістю `slots_variant` з кожною подією і в
посилання на запис як `utm_content=slots-a` чи `slots-b`.

Обидва варіанти можна подивитись адресою з `?slots=a` або `?slots=b`.
Рахувати через місяць після переїзду домену: частку показів панелі
(`slots_shown`), що закінчились натиском (`slot_tap`), рівні й ціни в
`slot_tap`. Щоб закінчити тест, лишити в `slotsVariant()` один варіант.

Посилання на запис ведуть на `n100000.alteg.io`. Домен `yclients.com`
не використовувати: він не відкривається з України.

## Свідомі рішення

- З 20:00 до 9:00 над шапкою світла смуга «Зараз зачинено, дзвінки
  приймаємо з 9:00». «Подзвонити» в герої й шапці лишається, але вікно
  дзвінка тоді каже, що зачинено, і пропонує «Записатись онлайн»; номери не
  набираються, позначені «з 9:00», і їх можна скопіювати іконкою поруч:
  третину онлайн-записів роблять саме в цей час. Години в `src/lib/hours.ts`
  і ще раз у скрипті в `index.html`, міняти обидва. Подивитись удень:
  `?closed=tomorrow` (вечір) або `?closed=today` (ранок).
- Відео на першому екрані вантажиться лише на екранах від 768px і не в режимі
  економії трафіку. Телефон бачить постер. На старому сайті 4,3 МБ відео
  качались повністю і не гралися.
- Анімації мають запобіжник: якщо вкладка прихована і кадри не йдуть, вміст
  показується без анімації. Без нього сторінка у фоновій вкладці лишалась
  порожньою.
- Картки майстрів цілі, край наступної не показуємо.
- Довгого тире в текстах немає, це правило.
- Скрипти важать 131 КБ gzip: це React і motion, ціна бібліотеки
  motion-primitives. Ванільна версія (site-v2) важила 17 КБ; повернення до
  неї означає відмову від бібліотеки.
- Перевірка Impeccable (детектор 61 правило + ручний аудит): 0 знахідок
  детектора, контраст дрібного тексту піднято до 5:1, фокус, цілі, ландмарки
  й адаптив на пʼяти ширинах перевірені. Свідомі винятки від його планки:
  eyebrow над заголовками і однакова поява секцій, обидва з системи GBI за
  рішенням замовника.
